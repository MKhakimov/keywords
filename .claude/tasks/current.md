# Печать: в сетке только стартовое слово

Статус: в работе
Свет: 🟢 зелёный

## Проблема

На печати стартовые буквы стоят во всех клетках с их номерами. В журнальном образце напечатано только само стартовое слово (ЗАПЕВ), остальные клетки с этими номерами пустые.

## Решения

- Печать: буквы только в клетках стартового слова (`given` у клетки игровой проекции).
- Ключ на печати — с буквами стартового слова, как в образце (решение пользователя).
- Игра не меняется: там стартовые буквы по-прежнему расставлены во все клетки своих номеров.

## Прогресс

- [ ] `PuzzleGrid`: режим «только клетки стартового слова»
- [ ] Печатная страница использует этот режим
- [ ] Тест, typecheck, lint, build
