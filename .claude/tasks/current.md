# Ядро генерации: каркас, словарь, модель, валидатор, заполнение, шифр (этапы 0–4)

Статус: обсуждение
Свет: 🔴 красный

Основа — проектное решение `design_2026-11-22.md`. Цель задачи: рабочее ядро без UI, которое строит валидную головоломку из словаря и доказывает её корректность тестами.

## Требования

- Чистый TS в `src/core`, без зависимости от React/DOM.
- Детерминированность по seed.
- Валидатор независим от генератора и пишется раньше него.
- Ответ — N частей в закреплённых слотах (по умолчанию одна вертикальная колонка с двумя сегментами, как в референсе).
- Иллюстрация на этом этапе не нужна; шаблон `public/illustrations/placeholder.png` используется на этапе 5.

## Прогресс

### Этап 0. Каркас
- [ ] Vite + React + TS strict, pnpm
- [ ] SCSS Modules, ESLint, Vitest
- [ ] Базовая структура папок

### Этап 1. Словарь
- [ ] `scripts/build-dictionary.ts`: OpenCorpora + частотность НКРЯ
- [ ] Нормализация, фильтры, стоп-лист, белый список
- [ ] `public/dict/ru-nouns.v1.json` + атрибуция лицензии
- [ ] Индекс по маскам и поиск по шаблону, тесты

### Этап 2. Модель и валидатор
- [ ] Типы `Puzzle`, `Cell`, слоты, части ответа
- [ ] `validatePuzzle` + отчёт
- [ ] Эталонные корректные и сломанные сетки в тестах

### Этап 3. Шаблон и заполнение
- [ ] Генератор шаблона с маской void и слотами ответа
- [ ] CSP-заполнение с MRV, forward checking, рестартами
- [ ] Прогон 100 seed'ов: все валидны, время в лимите

### Этап 4. Шифр и единственность
- [ ] Назначение номеров, стартовое слово 1…n
