# Интерфейс: журнальная страница, игра, редактор, печать (этап 5 + печать из этапа 7)

Статус: в работе
Свет: 🟢 зелёный

Основа — `design_2026-11-22.md` и готовое ядро (`core-generator_2026-11-22.md`). Цель: из браузера создать головоломку, увидеть её как журнальную страницу, решить её и распечатать в PDF.

## Объём

Входит:
- генерация в Web Worker, словарь загружается из `public/dict/ru-nouns.v1.json`;
- форма создания: рубрика, заголовок, загадка, пояснение, ответ, тема, сложность, seed (с кнопкой «случайный»), иллюстрация (шаблон по умолчанию или загрузка файла);
- журнальная страница A4: рубрика-плашка, заголовок, пояснение, SVG-сетка с иллюстрацией в вырезе, иконки ключей у частей ответа, полоса ключа;
- режим «Игра»: выбор клетки, ввод буквы (буква ставится во все клетки с тем же номером и в ключ), стирание, навигация стрелками, «Проверить», без подсказок с ответом;
- режим «Редактор»: решённая сетка, список слов с координатами и направлениями, таблица шифра, отчёт валидации;
- печать: `@page A4`, `window.print()` → PDF, игровая версия без интерфейса;
- шрифты с кириллицей локально (Lobster — заголовок, PT Sans — текст и числа, через `@fontsource`).

Не входит (следующие задачи):
- генерация текстов и иллюстраций через LLM (этап 6);
- сохранение в IndexedDB, импорт/экспорт JSON (этап 7).

## Решения

- Игровой режим получает только `PlayView`; `Puzzle` с ответами — только редактору.
- Ввод: SVG для отрисовки, скрытый `<input>` для клавиатуры (мобильная клавиатура, вставка).
- Ключ показывает K ячеек (решение пользователя); стартовые буквы напечатаны красным.
