# Импорт и экспорт головоломок в JSON

Статус: ревью
Свет: 🟢 зелёный

Цель: переносить сохранённые головоломки между браузерами и делать резервные копии.

## Решения

- Формат файла: `{ format: "keywords-export", version: 1, exportedAt, items: [{ puzzle, progress, solved, createdAt }] }`. Картинки уже внутри `puzzle` (data URL) — файл самодостаточный.
- Экспорт: кнопка у каждой головоломки во «Моих головоломках» и «Экспортировать всё».
- Импорт: кнопка «Импорт JSON» там же.
  - проверка структуры файла и каждой записи;
  - каждая головоломка заново проверяется валидатором с решателем в Web Worker (файл мог быть изменён вручную);
  - id уже есть в хранилище — запись пропускается, существующая не трогается;
  - итог: добавлено / пропущено / отклонено с причинами.
- Прогресс из файла восстанавливается через ту же очистку, что и при открытии.
